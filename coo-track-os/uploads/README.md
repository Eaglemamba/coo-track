# Uploads

Place documents here for analysis and integration into `memory.md`.

## Supported Document Types

- Performance reviews
- Project retrospectives
- Leadership feedback (360s, peer reviews)
- Self-assessments
- Career development plans
- Mentoring notes

## How It Works

1. Drop files into this folder
2. Run `/review-memory`
3. Claude will offer to analyze new uploads and extract patterns into `memory.md`

## Naming Convention

Use descriptive names with dates:
- `2025-performance-review.pdf`
- `2025-Q4-project-retro.md`
- `leadership-360-feedback-2025.pdf`
