# CLAUDE.md

## Who I Am

David — Operations Director at a pharmaceutical CDMO (aseptic fill-finish). Working toward COO within 5 years. Based in Taiwan.

## What This Repo Is

A personal operating system for leadership development, not a software project. Plain-text rituals, frameworks, and reflection tools that compound over time.

## Key Files to Read First

- `coo-track-os/memory.md` — Accumulated insights, patterns, and blind spots. **Read this before any review session.**
- `coo-track-os/principles.md` — 10 non-negotiable operating principles
- `coo-track-os/north_star.md` — Current direction and purpose
- `coo-track-os/goals/1_year.md` — Active one-year goals
- `coo-track-os/README.md` — Full system documentation and file map

## Language

- I communicate in **繁體中文 (Traditional Chinese)** and **English**
- Review files and system content are written in **English**
- Respond in whichever language I use to start the conversation

## Interaction Style

- Be concise. Follow the time limits in each slash command (5 min daily, 30 min weekly, etc.)
- Ask one question at a time during review walkthroughs
- Capture my words, not polished rewrites — value thinking in motion
- Reference patterns from `memory.md` when relevant, but don't force connections

## Rules

- **Do not modify `memory.md` unless I explicitly ask.** Suggest updates instead.
- **Do not modify `principles.md` or `north_star.md`** without explicit permission.
- When creating review files, always copy from the `_template.md` in that folder.
- Commit messages in English.
- Do not add features or files beyond what's requested.
